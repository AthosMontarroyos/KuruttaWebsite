# Kurutta

Documentação de marca da Kurutta, em preparação para [brand.athosmontarroyos.com](https://brand.athosmontarroyos.com).

A especificação fechada está no Notion, na página Brand. Este repositório guarda a base do site: React, Tailwind CSS e Vite, os tokens monocromáticos e a referência raster v4 do 狂.

## Desenvolvimento

```sh
npm install
npm run dev
```

`npm run build` gera o site estático. `npm run lint` roda o oxlint.

## Assets

```text
src/assets/brand/logo/    símbolo e testes de redução
src/assets/brand/mascot/  reservado para a Kuruttina
public/                   favicon 32, favicon 16 e avatar
```

Nomes em minúsculas, com a versão no arquivo. Referências de terceiros ficam no Notion e não entram neste repositório.
